# Code of Conduct

CopyWeave is built for collaboration between writers, designers, developers, and AI-tool users. Treat all of them as legitimate participants.

## Expected behavior

- Be specific, patient, and generous with context.
- Critique work and trade-offs, not people.
- Respect names, pronouns, identities, experience levels, and communication styles.
- Credit prior work and disclose relevant interests.
- Keep security reports and private user material confidential.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized attention, doxxing, deliberate disruption, impersonation, and publishing another person's private information are not welcome in project spaces.

## Enforcement

Report conduct concerns privately to the repository maintainers through GitHub. Maintainers may edit or remove content, restrict participation, or ban accounts when needed to protect the community. Enforcement decisions should be documented privately, applied consistently, and avoid retaliation against good-faith reporters.

This policy applies in repository issues, pull requests, discussions, community calls, and public interactions made on behalf of the project.
