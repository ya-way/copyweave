# Roadmap

CopyWeave stays narrow: edit words in the composition without becoming a hosted CMS.

## 0.1 — Release candidate

- Semantic leaf fields and automatic migration mode
- Browser drafts and safe local project saves
- Static HTML apply, doctor, schema, demo, and Agent Skill

## 0.2 — Integration quality

- First-party Vite/Astro build adapter
- Attribute fields for `aria-label`, `alt`, `title`, and placeholders
- Better SPA route hooks and orphan-field reports
- Playwright browser matrix and screenshot-diff fixtures

## 0.3 — Editorial constraints

- Optional field descriptions, length guidance, and multiline types
- Locale files and translation-aware project structure
- Draft diff and review view

## Not planned for core

- Accounts, hosted storage, analytics, or telemetry
- Rich-text page builders
- A proprietary deployment platform
- Multi-user real-time collaboration

Open an RFC before expanding any of these boundaries.
