## [0.1.0] - 2026-08-11

### Added

- Framework-agnostic browser editor with explicit and automatic field discovery.
- Local browser drafts, versioned project JSON, import, export, and page reset.
- Loopback CLI with session tokens, ETags, atomic writes, backups, and strict path checks.
- `init`, `serve`, `doctor`, and conservative static HTML `apply` commands.
- English and Simplified Chinese UI.
- Demo, TypeScript declarations, IIFE build, JSON Schema, CI, Agent Skill, and two-pass QA workflow.
